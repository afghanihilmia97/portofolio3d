# Afghani Hilmi Al-Ghifari — 3D & Flat Portfolio (Vercel Ready)

Portofolio interaktif 3D WebGL & Flat OS untuk **Afghani Hilmi Al-Ghifari (Programmer × Digital Marketing)**.

## Cara Upload / Deploy ke Vercel

### Cara 1: Lewat GitHub (Paling Mudah & Gratis)
1. Ekstrak file ZIP ini.
2. Buat repository baru di GitHub, lalu upload `index.html` dan `vercel.json`.
3. Buka [vercel.com/new](https://vercel.com/new), login dengan GitHub, lalu klik **Import** pada repository tersebut.
4. Klik **Deploy** (Framework Preset biarkan **Other**). Website langsung online!

### Cara 2: Lewat Terminal (Vercel CLI)
1. Ekstrak folder ini dan buka terminal di dalamnya.
2. Jalankan perintah:
   ```bash
   npx vercel --prod
   ```
